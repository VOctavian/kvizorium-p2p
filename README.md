# Квизориум

Своя квиз-игра на табло «темы × цены», совместимая с паками `.siq` (форматы 4 и 5). Один код работает в браузере и в десктоп-версии для Steam.

## Запуск

```bash
npm install
npm run demo-packs   # собрать packs/demo.siq (уже лежит в репозитории)
npm run dev          # сервер :8787 + клиент :5173
```

Откройте http://localhost:5173. Чтобы поиграть вдвоём на одном компьютере, создайте комнату и запустите бота:

```bash
npx tsx tools/bot.ts КОД_КОМНАТЫ "Бот Вася"
```

### Паки для проверки

Лежат в `packs/` и видны в игре как встроенные:

| Файл | Что проверяет |
|---|---|
| `demo.siq` | Небольшая игра на 3 раунда с финалом |
| `test-all-types.siq` | Все типы вопросов формата 5: обычный, картинка, звук, видео, реплика ведущего, медиа в ответе, аукцион, кот в мешке (фиксированная цена, выбор цены, открытая цена, без вопроса), без риска, для всех, варианты ответа, длинный текст для постепенного показа, финал |
| `test-format4.siq` | Старый формат 4: атомы, `voice`, `say`, маркер ответа, `cat`, `bagcat`, `auction`, `sponsored`, финал |
| `test-wide.siq` | 6 тем по 15 вопросов: табло должно помещаться без прокрутки; второй раунд и финал для смены раундов |
| `test-15-themes.siq` | 15 тем, одна с названием в 150 символов: шрифт названий подстраивается под ячейку, длинное переносится на несколько строк; второй раунд — 15 × 15 |

### Ведущему

- Под чатом вкладки: «Чат», «Очки» (правка счёта всех игроков), «Комната» (информация и настройки игры), «Аккаунт» (имя, аватар, пол), «Настройки» (громкость медиа и сигналов, язык, графика, анимации).
- Правый клик по игроку: «Передать ход», «Сделать ведущим», «Выгнать…» с подтверждением (стол уходит вместе с игроком). Передать ход можно и списком под табло.
- «+ Стол» в ряду игроков добавляет место; зритель садится кнопкой «Сесть».
- «Редактировать табло»: клик по теме или вопросу убирает или возвращает его.
- «Раунд ▾» в шапке: переход к любому раунду, он начинается с начала.
- Наведение на ответ в ленте чата: «Верно»/«Неверно», «×2», «0,5», «0».

Пересобрать: `npm run demo-packs` (видео для пака: `npx electron tools/make-video.cjs`).

Если игра тормозит, в профиле есть «Графика»: «Быстро» убирает анимацию фона, «Красиво» включает размытие стекла.

### Совместимость с .siq

Типы вопросов SIGame (`SIPackages/Core/QuestionTypes.cs`): `simple`/`withButton`/пустой → обычный; `stake` и старый `auction` → аукцион; `stakeAll` → ставка для всех; `secret`, `secretPublicPrice`, `secretNoQuestion` и старые `cat`/`bagcat` → кот в мешке; `noRisk`/`forYourself` и старый `sponsored` → без риска; `forAll` → вопрос для всех. Параметры: `question`, `answer`, `theme`, `price` (`numberSet`), `selectionMode`, `answerType` (`text`, `number`, `select`), `answerOptions`, `answerDeviation`. Не поддержаны пока `answerType="point"` (ответ точкой на картинке) и `answerDuration`.

Продакшен-сервер (раздаёт и клиент, и игру):

```bash
npm run build
PORT=8787 npm start
```

## Структура

| Папка | Что внутри |
|---|---|
| `packages/siq` | Парсер `.siq`: `content.xml` форматов 4 (atoms) и 5 (params/items), поиск медиа с экранированными именами, сборщик паков |
| `packages/protocol` | Типы сообщений клиент ⇄ сервер, сверка ответов для автоведущего |
| `apps/server` | Node + WebSocket: комнаты, раунды, аукцион, кот в мешке, вопрос без риска, финал, чат с лентой событий, раздача медиа с поддержкой Range |
| `apps/web` | React + Vite, дизайн «стекло и аврора» (макет в `design/aurora-mockup.html`) |
| `apps/desktop` | Electron: поднимает сервер внутри приложения и открывает клиент; F11 — полный экран |
| `tools` | Генератор демо-пака и тестовый бот |

## Языки

Интерфейс на русском (по умолчанию) и английском; язык переключается в «Настройках» без перезагрузки и хранится на устройстве.

- Тексты клиента — `apps/web/src/i18n.ts`: словари `ru` и `en` одной формы, хук `useT()` в компонентах и `tr()` вне их. Новый текст добавляется в оба словаря, иначе `npm run typecheck` не пройдёт.
- Тексты сервера (лента, реплики ведущего, ошибки, статус раунда, загрузка пака) уходят ключом с параметрами (`Text` в `packages/protocol/src/text.ts`), клиент рисует их на своём языке. Для ботов и логов сервер по-прежнему кладёт русский текст в `ChatItem.text` и `error.message`.
- Не переводятся данные: содержимое паков, имена игроков и комнат, сообщения парсера `.siq` об ошибке в паке.

## Десктоп и Steam

```bash
npm run desktop        # собрать и открыть окно
npm run desktop:dist   # папка с приложением в apps/desktop/release
```

Десктоп-версия сама запускает сервер на порту 8787 (или на свободном, если он занят), поэтому друзья в локальной сети подключаются по IP этого компьютера: «Сервер игры» на экране входа.

Чтобы подключить Steam:

1. Получите App ID в Steamworks и впишите его в `apps/desktop/steam_appid.txt` (сейчас там тестовый 480 — Spacewar).
2. `npm install -w @kvz/desktop steamworks.js`
3. При запуске из Steam имя игрока подставится из профиля, включится оверлей.

Онлайн-игра через интернет пока идёт через выделенный сервер (`npm start` на VPS). Сетевой слой Steam (лобби, приглашения друзей) — следующий шаг.
