# Деплой на Oracle Cloud Always Free

Понадобится банковская карта (Oracle проверяет её, бесплатные ресурсы не списывают деньги) и 30–40 минут.

## 1. Регистрация

1. Откройте <https://www.oracle.com/cloud/free/> → **Start for free**.
2. **Home Region** выбирается один раз и навсегда, и бесплатные ARM-серверы есть только в нём. Берите регион поближе к игрокам (например, Frankfurt, Amsterdam, Stockholm).
3. Подтвердите почту, телефон и карту. Аккаунт может активироваться не сразу, иногда до получаса.

## 2. SSH-ключ на вашем компьютере

В PowerShell (на все вопросы — Enter):

```powershell
ssh-keygen -t ed25519
Get-Content $HOME\.ssh\id_ed25519.pub
```

Вторая команда выводит публичный ключ — строку, которая начинается с `ssh-ed25519`. Она понадобится на следующем шаге.

## 3. Сервер

**Compute → Instances → Create instance**:

- **Image**: Canonical Ubuntu 24.04 (обычная, не Minimal).
- **Shape** → Change shape → **Ampere** → `VM.Standard.A1.Flex`: **2 OCPU, 12 GB**. Это бесплатный лимит. На старых аккаунтах он может быть 4 OCPU / 24 GB; лимит не превышайте, иначе машину могут выключить.
- **Networking**: создать новую сеть (VCN) с публичной подсетью, **Assign a public IPv4 address** — да.
- **Add SSH keys** → Paste public keys → вставьте строку из шага 2.
- **Boot volume** — как есть (бесплатно до 200 ГБ на все диски).

Нажмите **Create** и запишите **Public IP address**.

Если пишет *Out of capacity*: попробуйте другой Availability Domain или повторите позже, бесплатные ARM-машины разбирают.

## 4. Порты в облаке

Откройте сервер → **Subnet** → **Security List** → **Add Ingress Rules**. Добавьте два правила:

| Source CIDR | IP Protocol | Destination Port |
|---|---|---|
| `0.0.0.0/0` | TCP | `80` |
| `0.0.0.0/0` | TCP | `443` |

Брандмауэр внутри самого сервера откроет скрипт установки.

## 5. Домен

Нужен HTTPS: шифрование пака и WebRTC в браузере работают только на защищённых страницах.

- **Свой домен**: A-запись на IP сервера.
- **Бесплатно**: войдите на <https://www.duckdns.org>, придумайте имя, впишите IP сервера. Получится адрес `имя.duckdns.org`.

## 6. Проверка SSH

```powershell
ssh ubuntu@IP_СЕРВЕРА
```

На вопрос про ключ сервера ответьте `yes`, затем `exit`.

## 7. Выгрузка игры

В папке проекта:

```powershell
powershell -ExecutionPolicy Bypass -File deploy\upload.ps1 -Server IP_СЕРВЕРА -Domain имя.duckdns.org
```

Скрипт собирает игру, отправляет её на сервер и запускает [setup.sh](setup.sh). Тот ставит Node.js и Caddy, открывает порты, запускает игру как службу и получает сертификат HTTPS. Первый раз это занимает 3–5 минут.

Откройте `https://имя.duckdns.org`.

## Обновление

Та же команда из шага 7. Комнаты и игроки переживают обновление: сервер сохраняет их перед остановкой.

## Полезное

- Журнал игры: `ssh ubuntu@IP` → `sudo journalctl -u kvizorium -f`.
- Данные (комнаты, игроки, статистика): `/var/lib/kvizorium` на сервере.
- Десктоп-версия: в поле «Сервер игры» укажите `https://имя.duckdns.org`.
- **Oracle может забрать бесплатную машину, которая неделю почти не работает.** Чтобы этого не случилось, переведите аккаунт на **Pay As You Go** (Billing → Upgrade). Бесплатные ресурсы останутся бесплатными. Заодно заведите бюджет с оповещением на $1 (Billing → Budgets), чтобы сразу узнать, если что-то вышло за лимит.
