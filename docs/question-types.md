# Типы вопросов в Квизориуме

Здесь собраны все варианты вопросов, которые Квизориум понимает в паках `.siq`, и их сочетания. У каждого вопроса есть четыре независимых свойства:

1. **Тип**: кто отвечает и как начисляются очки.
2. **Тип ответа**: в каком виде нужен ответ (текст, число, вариант из списка).
3. **Содержимое**: что видно на экране (текст, реплика ведущего, картинка, звук, видео) и в каком порядке.
4. **Раунд**: обычный или финальный.

Плюс настройки комнаты меняют поведение: классическая или простая игра, устная или письменная, есть ли ведущий.

---

## 1. Типы вопросов

| Тип | Как записан в паке | Кто отвечает | Очки |
|---|---|---|---|
| **Обычный** | формат 5: `type` нет, `simple`, `withButton`, пустой; формат 4: без `type` | Кто первым нажал кнопку. После ошибки кнопки снова открыты для остальных | Верно: +цена. Неверно: −цена (если включён штраф за ошибку) |
| **Аукцион** | 5: `stake`; 4: `auction` | Победитель торгов. Торгуются по очереди: ставка выше текущей, пас или ва-банк. Ва-банк перебивается только ва-банком на большую сумму | ±ставка |
| **Кот в мешке** | 5: `secret`; 4: `cat`, `bagcat` | Тот, кому выбравший отдал вопрос. Остальные ответить не могут, даже если получатель ошибся | ±цена кота (своя тема и цена из пака) |
| **Кот с открытой ценой** | 5: `secretPublicPrice` | Как кот в мешке | Как кот в мешке (цена видна всем заранее) |
| **Кот без вопроса** | 5: `secretNoQuestion`; 4: `bagcat` с `knows=never` | Никто не отвечает | Получатель сразу получает цену |
| **Вопрос без риска** | 5: `noRisk`, `forYourself`; 4: `sponsored` | Только выбравший вопрос | Верно: +2×цена. Неверно: 0 |
| **Вопрос для всех** | 5: `forAll` | Все игроки одновременно, каждый пишет ответ или выбирает вариант. Можно спасовать | У каждого ±цена |
| **Ставка для всех** | 5: `stakeAll` | Все, у кого счёт больше нуля: сначала тайная ставка, потом ответ | У каждого ±своя ставка |

### Цена кота в мешке

| В паке | Что происходит |
|---|---|
| Одно число | Цена фиксирована |
| Диапазон `numberSet` (минимум, максимум, шаг) | Получатель выбирает цену из диапазона |
| `0` / диапазон `0..0` | Минимум или максимум цены раунда, на выбор получателя (как `bagcat` в формате 4) |

### Кому можно отдать кота (`selectionMode`)

| Значение | Кому |
|---|---|
| `exceptCurrent` (по умолчанию; `cat` в формате 4) | Любому, кроме себя |
| `any` (`bagcat` с `self=true`) | Любому, включая себя |

## 2. Типы ответа

| Тип ответа | Как записан | Как проверяется |
|---|---|---|
| **Текст** | по умолчанию, `answerType=text` | Ведущий решает сам. Без ведущего сервер сравнивает с правильными ответами, прощая регистр, «ё», знаки и мелкие опечатки |
| **Число** | `answerType=number`, допуск `answerDeviation` | Как текст, плюс автоматически засчитывается число в пределах ±допуска |
| **Варианты** | `answerType=select` и список вариантов | Игрок нажимает на вариант, сервер проверяет **сам**, без ведущего. Ошибочные варианты зачёркиваются. Когда остались только правильные, вопрос заканчивается |
| **Место на картинке** | `answerType=point`, ответ `x,y,высота/ширина` (доли от 0 до 1), допуск `answerDeviation` | Отвечающий нажимает на картинку вопроса, сервер проверяет **сам**: засчитывается попадание в круг радиусом «допуск × длинная сторона картинки» (по умолчанию 0,1). Промахи остаются метками на картинке, при показе ответа видна правильная зона. Работает и в вопросах «для всех», в ставках для всех и в финале: там при показе ответа на картинке видны клики всех игроков |

Неправильные ответы из пака (`<wrong>`) ведущий видит как подсказку.

## 3. Содержимое вопроса

| Элемент | Формат 5 | Формат 4 | Показ |
|---|---|---|---|
| Текст | `item` без типа | `atom` без типа | Буквы подсвечиваются по мере чтения (караоке), скорость задаётся в настройках |
| Реплика ведущего | `item` с `placement="replic"` | `atom type="say"` | Отдельной строкой «Ведущий: …» |
| Картинка | `type="image"` | `type="image"` | Растёт до краёв блока. Можно включить показ построчно сверху вниз |
| Звук | `type="audio"` | `type="voice"` | Играет сам, без кнопок управления у игроков |
| Видео | `type="video"` | `type="video"` | Играет само, без кнопок управления у игроков |
| HTML | `type="html"` | — | Ссылкой |

Как это работает на экране:

- **Порядок.** Пока ведущий «читает», элементы появляются **по очереди**: текст, потом первая картинка, потом вторая и так далее. Место под ещё не показанные элементы занято заранее, поэтому ничего не прыгает.
- **Свой пак (до 150 МБ) раздаётся между игроками.** Браузер лидера распаковывает пак и шифрует каждый файл своим ключом. Сервер получает только вопросы и список файлов. Зашифрованные файлы идут от браузера к браузеру (WebRTC), каждый проверяется по хэшу и хранится в браузере. Ключ к файлу сервер выдаёт, когда файл появляется на экране, поэтому заглянуть вперёд нельзя. Игра начинается, когда у всех за столом есть первый раунд (лидер может начать и раньше).
- **Встроенные паки и загрузка заранее.** Их медиа отдаёт сервер. С началом раунда браузеры в фоне скачивают картинки, звук и видео всех вопросов раунда (медиа ответов — нет). Когда весь раунд есть у всех игроков и ведущего, начинается загрузка следующего раунда.
- **Загрузка перед вопросом.** Если в вопросе есть картинка, звук или видео, сначала все игроки и ведущий загружают файлы (до 8 секунд), и только потом начинается чтение. Так никто не видит вопрос раньше других. Если раунд уже скачан заранее, ожидания нет.
- **Текст рядом с медиа.** Он сжимается в одну строку: сначала уменьшается шрифт, если и так не влезает, текст обрывается многоточием, а полный виден во всплывающей подсказке.
- **Несколько картинок или видео подряд** встают в один ряд.
- **Медиа в ответе** показываются вместо вопроса, когда открывается правильный ответ.

## 4. Раунды

| Раунд | Механика |
|---|---|
| **Обычный** | Табло с темами и ценами. Выбирает тот, кто последним ответил верно (в начале — случайный игрок или по решению ведущего) |
| **Финальный** (`type="final"`) | Играют те, у кого счёт больше нуля. По очереди убирают по одной теме. На оставшуюся тему все тайно ставят, пишут ответ, ведущий проверяет. Каждый получает ±свою ставку |

Если в паке несколько финалов, настройка «Финалы» выбирает, играть все или только первый.

---

## 5. Сочетания

### Тип × тип ответа

| | Текст | Число | Варианты |
|---|---|---|---|
| Обычный | ✔ ведущий | ✔ ведущий или допуск | ✔ автоматически, отпадающие варианты |
| Аукцион | ✔ | ✔ | ✔ автоматически (отвечает один) |
| Кот в мешке | ✔ | ✔ | ✔ автоматически (отвечает один) |
| Без риска | ✔ | ✔ | ✔ автоматически (отвечает один) |
| Для всех | ✔ ведущий проверяет каждого | ✔ | ✔ кнопки вариантов, автоматически |
| Ставка для всех | ✔ | ✔ | ✔ кнопки вариантов, автоматически |
| Кот без вопроса | — ответа нет | — | — |
| Финал | ✔ ведущий проверяет каждого | ✔ | ✔ |

### Тип × содержимое

Любой тип можно сочетать с любым набором содержимого: только текст, текст и одно или несколько медиа, только медиа (например, вопрос-мелодия), реплика ведущего, медиа в ответе. Исключение — кот без вопроса: у него содержимое не показывается.

### Как настройки комнаты меняют типы

| Настройка | Влияние |
|---|---|
| **Простая игра** | Аукцион, коты, без риска, для всех и ставка для всех играются как обычные вопросы. Финальные раунды пропускаются |
| **Устная игра** | Игрок говорит ответ вслух, ведущий оценивает. Нужен ведущий на месте; без него ответы пишутся |
| **Без ведущего** | Сервер сверяет ответы с паком. Множители и правка очков недоступны |
| **Штраф за ошибку выключен** | Неверный ответ стоит 0 (кроме ставок) |
| **Фальстарт** | Нажал кнопку до того, как её открыли, — секунда блокировки |

### Оценка ведущим

Ответ одного игрока ведущий оценивает множителем от цены: ×2, ×0,5, верно (×1), 0, неверно (×−1), неверно ×0,5, неверно ×2. Ноль считается как пас: карточка игрока становится серой, остальные могут ответить. Любую оценку можно исправить потом, наведя мышь на событие в ленте.

### Как вопрос может закончиться

- Кто-то ответил верно.
- Все ошиблись или спасовали.
- Время на раздумье вышло.
- Ведущий нажал «Дальше» (стрелка вправо).
- В вопросе с вариантами остались только правильные варианты.
